# MMHD
High resolution textures to be used with either the PC ports or GlideN64 plugin. The Zelda64Recompiled port is the definitive version and has enhancements that weren't possible on emulators.

The 2ship port still has issues with custom texture support that prevent it from having parity with the recomp, but GhostlyDark is working on a modified version of the pack for it: https://evilgames.eu/texture-packs/mm-reloaded.htm#close

If you still want to use emulation, Project64 is no longer recommended due to rampant technical issues with the emulator- please use RMG instead: https://github.com/Rosalie241/RMG/releases/latest
